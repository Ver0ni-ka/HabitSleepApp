# Habit & Sleep Tracker

A full-stack web application designed to help users track their daily habits and sleep patterns, promoting a healthier lifestyle and routine. Developed as a Bachelor's thesis project.

## Key Features

* **Authentication System:** Secure user sign-up, login, Google OAuth 2.0 and profile management.
* **Habit Tracking:** Create, edit, and log daily habits.
* **Sleep Tracker:** Record sleep duration and quality.
* **Data Analytics:** Visual charts to analyze habits and sleep history over time.
* **PWA Support:** Installable as a Progressive Web Application on mobile and desktop devices.
* **Minimalist UI:** Clean, responsive, pastel-blue interface for a comfortable user experience.

## Tech Stack

* **Backend:** Python, Django
* **Frontend:** Django Templates, HTML5, CSS3, JavaScript
* **Database:** PostgreSQL
* **Other:** Progressive Web App (PWA)
